# Lusso di Firenze — concept homepage

Single-file concept homepage (`index.html`) by BEYOUROWN. Not the live store.

- Real-time WebGL perfume bottle (three.js r160): reflective glass, refracting liquid, gold-foil plaque, marble plinth, bloom.
- Scroll story: hero drop-in → **Anatomia** (Majesty Noir notes orbit the bottle in top / heart / base rings) → **Collezione** (bottle re-colours and spins per fragrance, giant name refracts through the glass) → **Build your box** → craft.
- Drag to turn the bottle, click it to spritz.

Open `index.html` in a browser (needs network for three.js, Lenis and Google Fonts from CDNs).
