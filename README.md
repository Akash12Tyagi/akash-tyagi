# Lusso di Firenze — concept homepage

Single-page concept homepage (`index.html` + `assets/`) by BEYOUROWN, built to the Lusso di Firenze brand guidelines. Not the live store.

- **Brand system:** Vivid Red `#BD0000`, Black, Warm Off-White `#FAF7F2`, Soft Gray `#E9E9E9`; Lufga (Outfit stands in until Lufga is self-hosted) + Poppins; official logo and photography.
- **3D:** real-time three.js bottles in the three real shapes (round, octagonal, square) with transmissive glass, refracting liquid and printed labels, on a travertine plinth. Drag to turn, click to spritz.
- **Scroll story:** hero → Majesty Noir notes (dark set, notes orbit the opened bottle) → collection (bottle morphs shape and colour per fragrance) → four brand pillars → Amber Nomad quote → photography → build-your-box → CTA.

Serve the folder over HTTP to view (`python3 -m http.server`), since the labels are drawn from the logo images. three.js, Lenis and Google Fonts load from CDNs.

MRP/discount figures are placeholders until live pricing is supplied.
